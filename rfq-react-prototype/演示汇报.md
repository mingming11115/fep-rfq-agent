# FEP RFQ 提效 Agent 原型演示汇报

## 简短汇报稿（约 1 分钟）

本次完成了 FEP 销售 RFQ 提效 Agent 的 React 交互原型，覆盖需求文档中的 13 个主页面，界面参考 Ant Design Pro 的查询表格布局。

原型围绕“项目建立、RFQ 解析核对、应答确认、偏离项处理、审批导出”展开，同时覆盖机型能力、知识、证据、版本和审计维护。演示中可以直接编辑应答、切换角色、处理评审，并下载 CSV 草稿。

重点验证了业务流程中的控制规则：系统建议需要人工确认，答复修改后原确认失效，未关闭事项阻止正式导出，最终批准与编制身份分离。

当前阶段用于评审页面和交互流程，数据、解析及检索结果均为模拟，尚未接入真实 OCR、AI 或业务后端。下一步结合销售与技术反馈确认流程，再安排真实数据和服务接入。

## 演示顺序（约 3 分钟）

1. **项目列表与解析**：查看示例项目；新建项目后，可载入示例 RFQ、核对来源并选择条目导入。
2. **细则确认**：展示客户要求、人工应答和匹配依据；修改并保存答复，再切换技术确认人完成单条确认。
3. **偏离项与导出**：展示处理方案、批准入口及导出缺项检查；说明未完成事项会阻止正式导出，内部草稿可以下载。
4. **能力与追溯**：展示机型元数据、能力边界、证据及版本记录，说明知识维护与项目应答之间的联系。
