# BHEL 半导体 RFQ 原型演示

默认项目：BHEL · 硅晶圆激光切割设备（RFQ-BHEL-2018）。

原始文件为 PDF，并非 Word。BHEL 官网公开发布的 IKCCAP0034，发布于2018年1月10日、截止于2018年1月31日。本案例仅作历史演示。

## 三分钟演示顺序

1. 打开 RFQ解析：展示43页原PDF，以及按原始章节整理的40条精选要求。左侧章节保留原编号，中间查看英文原文，右侧为中文译文。点击“打开原始PDF”可查看完整原件；此案例为人工核对的数据，不代表已接入OCR或AI解析。
2. 找到 Table-1 第8项“最大切缝宽度”，点击进入细则比对：真实要求≤50 μm。模拟能力为60 μm，且1.2 mm硅晶圆工况未验证，展示附条件答复、样品验证和证据缺口。
3. 查看 RFQ 第6条“设备交付周期”：真实要求自采购订单起12周；模拟排产16周，差距4周。演示商务偏离的处理方案与审批。
4. 在偏离处理中，查看“1 mm与1.2 mm演示厚度不一致”和“质保起算与截止口径核对”。两者均来自原文件内部表述差异；保留原文并登记澄清，未向客户发出任何消息。
5. 展示导出检查与CSV草稿。所有答复初始均待确认；未完成确认、评审与最终审批时不能正式导出。原有规则还会为缺少依据的条款自动创建补证评审。

## 数据边界

- 真实：采购方、RFQ编号与历史日期、原始PDF、精选条款英文摘录、原编号及PDF页序。中文为演示译文，精选条款不覆盖全文。
- 模拟：DEMO-YAG 150机型、60 μm能力、16周排产、匹配置信度、标准与历史答复、证据、人员与评审操作。客户要求不能当作供应商能力证明。

- 新上传其他文件仍只登记元数据并走模拟解析。
