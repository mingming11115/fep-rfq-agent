# FEP RFQ React 交互原型

参考 Ant Design Pro 查询表格的布局和操作方式，使用 React + Vite 实现现有 PRD 与交互设计中的 13 个主页面。界面为中文，数据为模拟数据，操作保存在当前浏览器的 localStorage。

快速使用：[启动说明](启动说明.md) · [演示汇报稿](演示汇报.md)

## 启动

```bash
cd rfq-react-prototype
npm install
npm run dev
```

打开终端显示的 HTTP 地址，默认 http://127.0.0.1:5173。使用 `npm run build` 构建静态文件到 `dist/`；`npm test` 运行确认、版本、快照与 CSV 相关行为测试。

## 页面覆盖

| 编号 | 页面 | 主要交互 |
| --- | --- | --- |
| PG-01 | 项目列表 | 查询、勾选、摘要、新建项目、进入项目 |
| PG-02 | RFQ 解析 | 上传元数据、模拟队列、来源对照、编辑、拆分、合并、补录、部分确认 |
| PG-03 | RFQ 细则确认 | 三栏比对、草稿、证据、条件、确认、批量检查、转评审、补充能力 |
| PG-04 | 偏离项管理 | 筛选、分派、方案、审批、退回、重开、沟通与验收 |
| PG-05 | 导出文档 | 模板映射、草稿下载、缺项检查、冻结快照、独立审批、CSV 导出 |
| PG-06 | 知识与结果 | 查询、详情、编辑、导入候选、审核、发布、撤销、结果反馈 |
| PG-08 | 个人工作台 | 待办筛选、项目进度、最近动态、快捷进入 |
| PG-09 | 项目设置 | 基本资料、设备配置、成员职责、审批配置及变更复核 |
| PG-10 | 资料与证据 | 元数据上传、详情、有效性、影响引用与版本 |
| PG-11 | 版本记录 | 工作、文件、快照标签；版本详情、人工影响核对 |

| PG-13 | 系统配置 | 账号、业务、模板、运行状态及只读备份记录 |
| PG-14 | 机型能力边界 | 机型元数据与能力边界两个标签；来源、候选、修订、独立审核、发布 |

## 演示方式

顶部“演示身份”可切换销售负责人、技术确认人和最终审批人。专业确认由技术确认人代行演示；最终审批人与提交人分离。更改已确认的答复会撤销原确认，未关闭评审或未完成确认的内容阻止正式导出。

这是交互评审原型。上传只保存文件元数据，解析和检索使用明确标注的模拟结果；没有连接实际 OCR、模型、企业认证或生产数据库。CSV 可以实际下载，正式应答仍须按企业流程复核。知识、资料和能力页面独立保存演示状态，核心“重置演示”保留这些独立记录。
