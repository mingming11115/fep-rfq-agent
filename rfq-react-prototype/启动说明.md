# FEP RFQ 原型启动说明

## 在这台电脑上启动

1. 打开 macOS「终端」，复制以下两行并回车：

   ```bash
   cd "/Users/l/Documents/ChatGPT/RFQ提效agent/rfq-react-prototype"
   npm run dev
   ```

2. 看到 `Local: http://127.0.0.1:5173/` 后，用浏览器打开：

   [http://127.0.0.1:5173/](http://127.0.0.1:5173/)

3. 演示期间保持终端窗口打开。结束时在终端按 `Control + C`；下次重复以上步骤。

本机已安装依赖；如果页面已经能打开，就无需重复启动。提示端口 `5173` 被占用时，先打开上面的地址查看是否已有原型在运行。

## 第一次在其他电脑上启动

需先安装 Node.js（22.12 或以上版本）和 Git。在终端依次执行：

```bash
git clone https://github.com/mingming11115/fep-rfq-agent.git
cd fep-rfq-agent/rfq-react-prototype
npm ci
npm run dev
```

首次下载代码和安装依赖需要网络，私有仓库还需 GitHub 访问权限。之后打开同一个本机地址；此地址只在启动服务的电脑上可用。

## 怎么体验

- 从「项目列表」进入示例项目，再依次查看「RFQ 解析 → RFQ 细则确认 → 偏离项管理 → 导出文档」。
- 顶部「演示身份」可切换销售负责人、技术确认人、最终审批人，体验草稿、确认和批准。
- 查看「机型能力边界」的「机型元数据」「能力边界」两个标签，体验能力维护。
- 修改会保存在当前浏览器中。「重置演示」仅恢复核心项目数据，知识、资料和能力维护记录继续保留。

当前为交互原型：使用模拟数据，上传仅登记文件元数据，尚未接入真实 OCR、AI、企业登录或数据库；CSV 草稿可实际下载。
