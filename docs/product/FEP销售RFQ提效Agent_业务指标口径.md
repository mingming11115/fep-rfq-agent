# FEP 销售 RFQ 提效 Agent 业务指标口径

人工流程与 Agent 流程使用相同的资料范围和初稿完成标准。条款质量依据客户原件、专家标注及对应版本的应答记录核对。

| 指标 | 统计口径 |
| --- | --- |
| 初稿人工工时降幅 | （人工流程工时中位数 − Agent 流程工时中位数）÷ 人工流程工时中位数。从建项目到产出可审核初稿，累计销售和技术的实际操作工时，等待时间单列。 |
| 按期出稿率 | 截止前完成正式导出的项目数 ÷ 本期到期项目数。到期仍未导出的项目计入分母。 |
| 关键条款缺陷数 | 对照客户原件，统计正式答复中漏答、答错或作出无依据承诺的关键条款数。同一条款有多项缺陷时计 1 条。 |
| 要求提取召回率 | 完整提取的要求数 ÷ 专家从客户原件标注的要求总数。完整提取须保留关键参数、单位及适用条件。 |
| 应答可用率 | 可直接采用或只需调整措辞的系统建议答复数 ÷ 抽查的系统建议答复总数。更改结论、参数或条件属于实质修改。 |
| 知识实际复用率 | 采用标准回复或历史答复、保留来源且无须实质改写的正式应答条款数 ÷ 全部正式应答条款数。 |

指标分母为零时记为「不适用」。产品验收的完整口径见 [PRD v0.2 §7.2](FEP销售RFQ提效Agent_PRD_v0.2.md#72-效果指标口径)。
