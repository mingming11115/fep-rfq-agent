# 系统推荐 Comply 的最终评审规则

- 用户要求：系统未推荐Comply的条目必须人工点击确认；系统推荐Comply但未人工确认的条目可以送最终评审，并放在评审最上方。
- 系统推荐与人工选择分开判断：当前结论和有效系统推荐均为Comply，且答复、证据完整、没有来源变更或待处理评审建议，才可免逐条确认送评。其他条目继续要求人工确认。来源变更、未关闭事项、缺失证据等原有检查继续生效。
- 解析导入时保存独立的系统推荐；历史条目使用现有模拟匹配来源恢复推荐，不能把人工改成Comply等同于系统推荐。
- 发起弹窗和只读审批详情最上方显示「系统推荐 Comply · 未人工确认」列表；冻结快照保留本轮条目ID及未人工确认状态，全文核对也优先显示这些条目。
- 审批仍需指定SR和技术组全部通过；通过后可正式导出。正式文件的确认状态标记为最终评审通过，保留快照内部未逐条人工确认的记录。
- 项目阶段和待办与新门禁保持一致；系统推荐Comply的有效条目不再产生强制逐条确认待办。

实现复用现有推荐、快照和最终评审流程，不新增审批服务。
