# 应答标注结论筛选菜单（第 8 项）

用户已确认：将五个结论复选框收进“筛选”菜单，保留多选、全选及清空；原文件旁及项目条款摘录使用相同布局。备选是保留五项平铺，用户选择菜单以减少常驻内容。

入口默认显示“全部结论”，部分或全部清空时显示“已选 N 类”。菜单展开后即时筛选，多选及全选/清空不自动关闭；关闭再打开保留选择，Esc 或点击外部关闭。Esc 返回入口焦点，键盘可打开和操作。清空等于不显示任何结论，沿用第 7 项空状态，不自动选择其他类别。新文件/来源版本仍按原有组件会话恢复全部结论。

实现选择复用现有 Ant Design Popover，弹层挂在页面以避开编辑器滚动容器裁切，并覆盖放大文件区。项目摘录显式使用同一筛选组件，文档处理页保留其既有平铺布局及范围。现有当前/全部标注切换、实时预览、定位、权限及保存行为不变，不增加业务写入或自动保存。每项独立提交并合并本地 master，后续 list 项继续逐项确认。
