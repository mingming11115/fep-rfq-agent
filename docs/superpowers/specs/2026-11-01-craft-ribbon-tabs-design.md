# RFQ Word 工具栏标签精简

用户要求在 `codex/rfq-craft-document-review` 通过代码统一去掉 Zotero、开发工具、邮件、引用、布局、设计、文件七个标签，所有人加载更新后的编辑器均生效。

采用 WordCraft 原生工具栏的显示过滤；内部标签名为 `Zotero`、`Developer`、`Mailings`、`References`、`Layout`、`Design`、`File`。旧个人偏好、功能区重置和窄屏“更多标签”菜单均不得恢复这些标签。保留其他普通标签、上下文标签，以及宿主的保存、上传、下载和批注功能。仅隐藏工具栏入口，不禁用文档排版或文件读写能力。

个人取消勾选只影响当前浏览器；启动时修改个人偏好可被重置。统一渲染过滤符合本次已经确认的要求，使用现有固定版本源码补丁分发，重新构建 WASM。

后续要求：Word 工具栏默认收起，仅保留标签栏。每次新建宿主编辑器时统一应用该默认值，覆盖旧浏览器的展开偏好；点击普通或“更多标签”菜单中的标签可展开工具。展开后不被逐帧的宿主初始化重新收起，既有收起操作继续可用。

2026-11-02 最终澄清：用户需要额外展示的目录导航，不能修改原 DOC 文件。撤回此前“插入正文目录”的入口；在原文件区标题栏提供“目录”开关，展开独立导航面板并支持点击跳转。优先读取已有标题，无标题时读取当前文档版本中可唯一定位的条款，再无条款则使用页码。打开、跳转和关闭只改变视图或光标，不插入内容、不设置标题样式、不修改文档版本、撤销历史或未保存状态，也不触发保存。七个标签继续隐藏，工具栏默认收起保持有效；原有正文编辑权限不变。

2026-11-02 标题行精简：用户要求去掉含 Discord 的整行。在 RFQ 宿主模式统一不渲染 Word 顶部标题行，包括自动保存、快捷按钮、搜索、Discord、头像和重复文件标题，并释放原来的高度。沿用现有原生源码补丁，不采用浏览器个人偏好（不能保证所有用户一致）或 CSS 遮挡 canvas（容易挡住正文或工具栏）。下方功能区标签、独立目录、批注、宿主文件标题和保存下载继续可用；独立 WordCraft 应用维持上游标题行。该操作不改变文档。

补充范围：用户要求同时去掉功能区右侧“编辑”模式按钮，包括启用修订时同位置的“审阅”菜单；释放该按钮及间距占用的宽度。仅隐藏模式切换入口，正文权限与修订设置不变，批注及分享按钮继续保留。用户明确本次“先改，不用打包”，因此只修改源码、重建本地预览并验证，不制作或发布新 ZIP。

最终补充：去掉宿主底部包含“重开保存稿、原件、批阅版、保存原文”的整行（Word/PDF 均适用）。已有快捷键保存、保存队列、离开页面保护继续有效；未保存/保存中状态放在已有文件标题说明中，实际保存失败时在错误提示中保留下载本地备份和重新打开操作。正常界面不增加替代文件操作行。

后续交付授权：用户要求合并推送到 `master`，并打包 Windows 所需资源，替代上一阶段“先改、不打包”的约束。提供匹配合并提交的编辑器资源、可直接运行的 Java 后端 JAR 和 Windows 启动说明；业务数据不入包。Windows Git 自动换行允许仅 CRLF→LF 的补丁散列等价，实际补丁内容变化仍拒绝；编译产物继续严格按原始字节校验。
