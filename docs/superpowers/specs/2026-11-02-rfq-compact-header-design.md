# 文档顶部单行布局（第 2 项）

用户已选择：合成一行，文件和状态在左，工具在右；搜索点击后展开。保留文件切换、来源版本、文件保存状态、唯一目录入口、搜索与现有筛选、话术批注开关和全屏，去掉重复文件标题。

采用单行宿主工具栏：将现有文件切换与应答工具放入原文件标题栏，文件名只在下拉框展示一次；保存状态来自当前文件的真实加载、保存队列及 dirty 状态，与应答保存状态区分。目录面板随文件区一起显示和放大。现有条款摘录切换保留为图标入口，批注工具条与定位提示留待后续逐项确认。

备选是两行且搜索常显，或仅移除重复标题；用户选择单行、点击展开搜索。窄区域对文件名做省略，工具使用有名称的图标；保存状态保留可访问名称，避免挤出操作。

文件切换、搜索和筛选继续走原有未保存检查；展开搜索、目录、标注与全屏不重新打开原件，也不触发文件保存。目录在放大状态下仍可使用。
