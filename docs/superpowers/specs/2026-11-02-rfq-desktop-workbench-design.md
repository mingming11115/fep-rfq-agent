# 第 11 项：桌面原文与应答空间

用户确认桌面原文 60%／应答 40%，保留拖拽和放大，空间不足时应答标注放到原文下方。随后明确“不用管手机”，本项只保留桌面调整，不引入手机全屏、原生 dialog、可见性 Context 或新的工作区外壳。

复用现有 Splitter 和保存/导航规则，默认比例改为 60%，桌面 Enter 也恢复 60%；方向键、拖拽和最小宽度继续保留。来源宽度不大于 900px 时标注移至下方，保留独立滚动；更宽的放大视图继续并排。调整视图不修改原文/应答、当前条款或 iframe 会话。

在隔离工作区实现，排除另一个聊天正在做的条款摘录/批注侧栏改动。第 11 项单独提交并合并 master，沿用用户要求推送 master 的授权；第 12 项总回归仍需确认。
