# RFQ 统一目录（第 1 项）

用户已确认：合并为一个“目录”入口，面板内切换“条款／文档标题”，默认显示条款；条款视图保留处理状态、搜索、筛选、勾选和批量确认。目录只导航，不修改原文。

采用宿主统一目录：沿用外层浮层和条款导航，在同一面板增加真实文档标题视图，移除文件标题行中重复的目录按钮。其他方案是只保留条款目录，或保留两个不同名称的目录入口，用户选择统一入口方案。

文档标题从 WordCraft 的真实正文标题结构读取，保留层级及编号；点击时校验文件会话和正文修订版本，通过原生只读导航命令跳转。无标题、原件未关联、正在加载、PDF 等场景显示对应提示，可切回条款视图。切换文件或来源版本时不显示上一文件的标题。

正文、撤销历史、文档修订号和未保存状态不得因读取或跳转改变，也不得触发保存。原有条款选择、未保存检查、批量确认和编辑权限继续使用既有逻辑。

本轮只实现第 1 项，其他精简项目逐项征得用户确认后再实施。沿用当前工作区及已有未提交修改，在新分支 codex/rfq-unified-directory 开发，不发布或制作 ZIP。

后续交付授权：用户在 master 合并交付会话明确选择“统一目录也一起合并”，因此已完成的第 1 项随界面精简和 Windows 兼容一起提交、合并推送至 master，并打包匹配资源。其余待逐项确认的精简不属于这次交付。
