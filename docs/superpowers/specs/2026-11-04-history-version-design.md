# 历史 RFQ 版本与比对

用户已在讨论文档版本、条款版本及双版本比对方案后要求实现。
沿用现有 React、本地元数据存储、IndexedDB 原件及解析服务。
上传可创建独立 RFQ 或关联已有文档创建新版本；版本链使用稳定 familyId、previousDocumentId 和递增 revision，客户版本文字独立维护。各版原件及条款独立，不覆盖旧版。新版本继承来源范围。
比对只允许同族可读文档，使用条款最新内部修订；先唯一相同要求、再唯一编号配对，歧义保守提示核对，不声称语义匹配。展示新增、删除、要求变更、答复变更、位置调整及未变，要求变化提示重新确认答复。可定位打开两版条款原文。
采用完整文档快照而非覆盖版本字段或仅存差量，以复用解析与原件下载。既有条款审核不跨文档版本继承。暂不提供跨项目语义检索、自动合并及企业共享持久化。
