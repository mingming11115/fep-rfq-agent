# RFQ 条款操作收敛

用户已批准：销售整理答复 → 提交技术确认 → 技术确认条款 → 最终审批整份应答。

条款页只突出当前角色的主操作：销售「提交技术确认」，技术「确认本条」，最终审批人在整份应答的审批页批准或退回。客户澄清与专项评审收进默认关闭的「问题处理」，已有事项仍可查看。

澄清表单仅展示销售跟进所需内容，不展示内部方案审批路线。专项评审表单保留技术方案及批准流程，名称与澄清分开。当前确认权限、版本校验、未关闭事项阻止确认、评审结果采用后重新确认均保留。

选择在现有操作区收拢入口；增加新流程页会增加跳转，仅改名称仍会保留并列操作。使用现有 React 和 CSS，不新增依赖，不改变已有数据。
