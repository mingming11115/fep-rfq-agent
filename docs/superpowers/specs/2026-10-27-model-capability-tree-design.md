# 机型与能力边界合并树页

用户已确认本会话展示的可交互草图，并要求按图实现。

- 使用一个“机型与能力边界”页面，移除原“机型元数据 / 能力边界”顶层标签。
- 左侧目录为 `BU → 机型（硬件版本）→ 工艺 → 能力条目`，可展开、收起和选中。机型只显示最新资料配置，能力条目保留资料版本标识。
- 右侧按节点显示 BU 机型目录、机型配置及下属工艺、工艺条件及能力清单、能力数值与条件证据。能力及工艺详情保留机型上下文，点击可回到机型配置。
- 旧能力没有有效工艺归属时，保留在原机型的“待关联工艺”分支，不猜测、不丢弃。停用工艺保留能力历史。
- 保留原新建、配置、修订、提交审核、独立发布、撤销、导入、证据及版本引用记录功能和 BU 权限边界。沿用现有本机存储和 React / lucide，不增加依赖或接入后端。
- 搜索可查找机型、工艺和能力，并保留命中项祖先；系列、生命周期、能力来源及状态筛选延续原能力。筛选或数据变更后选中项应有效，空 BU 可直接新建机型。
- 宽屏左右布局，窄屏树与详情上下排列，文字不溢出。

采用草图中的左树右详情方案，符合用户对层级及同页操作的确认。原标签页需要往返切换；整页树表在配置长文本和条件证据上阅读负担更大。
