# 按需展开 Word 编辑工具（第 3 项）

用户选择：默认隐藏整排，通过“编辑工具”开关展开。正文编辑和批注权限沿用现有规则。每完成一项，单独提交并合并到 master。

项目 Word 编辑器默认不渲染功能区的标签、工具和附属按钮，释放对应高度；宿主顶部提供“编辑工具”开关，展开时显示现有可用标签及当前标签工具，再次点击完全收起。原来统一隐藏的七个标签仍不出现。较窄文件区显示有名称和提示的图标，足够宽时显示“编辑工具”文字。

开关仅改变视图：不修改正文、批注、文档修订或撤销历史，不触发保存，也不授予编辑权限。重新配置当前条款不覆盖用户的展开选择；新文件/新编辑器默认隐藏。只读用户可以查看工具，既有权限继续限制修改。PDF 不增加 Word 工具开关；条款摘录下禁用开关，原文件返回后保留当前编辑器选择。独立 Demo 继续沿用原来的工具栏行为。

方案对比：用户选择默认隐藏整排、按需展开；未选择仅保留审阅/视图，或继续常显标签栏。本次仅实施第 3 项，不包含后续定位提示和批注入口调整，不制作发布包或推送远端。
