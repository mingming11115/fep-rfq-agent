# RFQ 界面层级与切换优化

目标：基于已统一的 antd / Pro 组件，减少模板感，增强日常工作中的层级和切换反馈。

采用克制的企业工作台方向：保留现有组件、权限、保存和评审流程。另一条方向是重做品牌和大幅增加视觉效果，但不符合当前工具型产品的使用场景。

- [x] 统一页面、Tab、视图与应答卡片动效；支持减少动态效果，打断旧动效；不等待动效才显示页面。
- [x] 去掉知识区重复页头和泛化说明；工作台显示实际用户与待办，降低装饰性统计卡权重。
- [x] 合并项目列表工具栏，使用 Segmented 切换卡片/列表，行内保留主要入口，其他操作收进 Dropdown。
- [x] 缩减查询表单空白；保持原生 antd 控件外观；调整可点击卡片的 hover/focus。
- [x] 验证主要切换、菜单动作、持久筛选、未保存拦截、减少动态效果及手机布局，保存前后截图和动态演示。

动效目标：页面约 180ms；Tab / 视图 140–180ms；确认卡片出入约 300ms。业务工作不依赖浏览器是否支持动画。

验证：新增动效控制行为测试先失败后通过，运行全部业务测试和构建，用浏览器检查真实交互和控制台。

完成记录：327 项测试通过，构建、差异检查及浏览器验收通过。独立复核指出工作台中等宽度裁切，浏览器复现后用容器断点修复；额外修复视图切换的焦点丢失，回归通过。保留原有工作区，不提交或发布。
