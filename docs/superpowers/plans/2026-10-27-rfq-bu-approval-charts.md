# BU 审批图表 Implementation Plan

**Goal:** 审批提效区展示可交互的趋势、区间及结果图表。

**Architecture:** 在已过滤的审批轮次上聚合图表数据，以独立 React/SVG 组件绘制。无新增依赖。

**Spec:** `docs/superpowers/specs/2026-10-27-rfq-bu-dashboard-design.md` 图表补充。

## Global Constraints

- 同一 BU、周期、真实／演示口径；不增加数据权限。
- 空分桶保持 null、折线断开；零时长仍为有效数据点。
- 结果占比只统计已通过／已退回，当前待审另列。

## Review Focus

- 分桶边界只统计一次，7／30／90天样本总数与指标一致。
- 空值与零值不同；单点、全零和空数据不生成无效坐标。
- 区间临界值4／8／24小时不重复。
- 切换 BU、周期和数据口径更新全部图表。
- 鼠标及键盘读数和窄屏布局可用。
