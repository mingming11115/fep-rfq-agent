# RFQ 项目最终评审规则实施计划

> **For agentic workers:** Use superpowers:executing-plans for inline execution of this authorized change.

**Goal:** 从 BU 管理移除技术组最终评审规则，在新建 RFQ 时选择并按项目保存。

**Architecture:** 项目保存 `technicalReviewSettings: {technicalMode, version}`。人员分派、最终评审与快照范围统一读取项目规则；旧项目复制当前 BU 规则，保持原快照范围与历史意见。

**Tech Stack:** React、现有 CSS、Node test runner。

**Spec:** 用户要求“技术组最终评审规则去掉，移动到新建 RFQ 配置中选择”；全员通过和负责人代表通过沿用现有规则。

## Global Constraints

- 默认全员通过；SR 方仍须单独通过。
- 不重置已有项目、浏览器数据、快照或评审意见。
- 保留当前工作区及其他并行修改；不自动提交或推送。

## Review Focus

- 同 BU 不同 RFQ 的规则彼此独立。
- 代表模式仍要求组内有效负责人。
- 旧项目及已删除可恢复项目迁移幂等，不使已有有效快照失效。
- 修改项目规则使待评审快照失效，旧 BU 规则变化不再影响已保存项目规则。
