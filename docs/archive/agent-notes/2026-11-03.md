## 新建回复库下拉框 Windows 上弹不出来（已定位）
- 根因：KnowledgeEditor 的字段用 `<label>` 直接包住 antd Select，原生 label 会把点击转发给 Select 内部 input，mousedown 开、click 关，弹层即开即关；不同浏览器事件时序不同，表现为 Mac 好而 Windows 弹不出。
- 修复：Mac 端提交 `3c778b6`（compound 控件移出 label，改 label htmlFor + id 关联）。Windows 仓库已在该提交，5173 服务代码含修复，`node --test src/knowledgeMaintenance.test.js` 通过（1 pass）。
- 若浏览器仍复现：Ctrl+F5 强刷清缓存即可。
