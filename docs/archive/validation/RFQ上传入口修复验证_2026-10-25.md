# RFQ 上传入口交互修复

## 问题与原因

用户反馈项目详情中的“上传与解析资料”跳转不合理、需要重复点击。浏览器复现确认：按钮只跳到 `documents`，未携带上传动作；解析页的上传弹窗默认关闭，所以必须再点一次上传。

## 修复

- 销售从空 RFQ 详情点击入口，直接进入上传弹窗，保留项目与原详情分区。
- 取消、关闭弹窗均返回同一个项目的原详情分区。
- 有效提交后关闭弹窗、清除上传动作，留在解析结果页观察处理进度；刷新不重复打开上传。
- 技术和最终审批人使用“查看来源资料”入口，旧上传动作链接仍不能打开上传表单。
- 解析队列、元数据保存和条款自动同步沿用原逻辑，未新增真实文档解析。

## 验证

- 修复前浏览器回归失败：单次点击不能看到上传弹窗。
- 新增三项导航回归，确认失败后实现，覆盖直达弹窗、只读角色、取消返回和提交后消费动作。
- 浏览器：`127.0.0.1` 现有空项目入口单次点击即弹出，取消返回相同项目详情；未改动该项目资料。
- 独立 `localhost` 演示存储实际选择 `RFQ测试文件_精密切割设备.docx`，开始模拟解析，条款自动同步，进入细则比对按钮可用，刷新未重开弹窗。
- 全量 `npm test`：100/100；生产构建通过，保留已有包体积提示；`git diff --check` 通过。
