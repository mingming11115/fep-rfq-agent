# 第 10 项：文件更多菜单与保存状态

用户确认：顶部更多菜单集中保存和下载，保留快捷键及失败恢复。单项范围不包括后续空间分配和总回归。

## 结果

- 文档工具栏右侧“更多”提供“保存批阅稿”（提示 Ctrl/Cmd+S）、“下载原件”、“下载已保存批阅稿”，不恢复底部操作行。
- 菜单保存使用现有原生桥、串行保存队列、If-Match 版本及检查点验证。只读、未就绪、摘录视图、请求或持久化中禁用保存；不改变原件或应答确认流程。
- 文件和应答保存状态明确分开。文件失败保持未保存保护，已有本地备份、重试及重新打开继续可用；生成文件前失败、尚无备份时，重试也重新请求保存。
- 两种下载走各自既有端点和访问凭据，下载不会保存或丢弃本地修改。下载失败独立显示重试下载，不覆盖文件保存错误或备份。
- 菜单支持 Esc 返回入口焦点、方向键导航；原生 iframe 交互、摘录/放大视图切换关闭菜单，原文实例保持不变。
