# 机型与能力边界树形合并页验证

用户确认左树右详情草图后，在现有 React 原型内实现。

## 页面与操作

- 删除“机型元数据 / 能力边界”顶层切换，目录统一为 BU → 机型/硬件版本 → 工艺 → 能力资料版本。
- 节点可展开、收起及选中，右侧直接显示相应BU目录、机型配置、工艺条件与能力清单，或能力范围、适用条件、限制和证据。工艺与能力详情可返回机型配置。
- 模型资料版本可切换；能力的旧版本与候选版本保留独立节点和版本标识。保存、新建、修订及调整归属后选中相应节点并展开其祖先。
- 系列、生命周期、来源及状态筛选保留；搜索命中机型、工艺或能力时保留祖先。未命中时显示空态，可清除筛选恢复。
- 旧能力在“待关联工艺”分支保留；技术仍可从机型或待关联视图新增尚无工艺的能力草稿。提交审核或发布仍要求有效工艺及证据。
- 现有BU配置权限、技术维护、独立审核发布、自审拦截、撤销、导入去重、版本审核记录及引用入口沿用。停用工艺保留历史并阻止新增、提交和发布。
- BU切换后按原存储键和权限隔离资料；空BU可新建机型和工艺，刷新后保留。宽屏左右布局，窄屏上下排列。
